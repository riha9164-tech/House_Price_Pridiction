About House Price Prediction

Predict house prices using Machine Learning and Flask.

Project Overview

This web application predicts house prices based on important property features using a Machine Learning model trained with Linear Regression.

The prediction is calculated using multiple parameters like Square Footage, Bedrooms, Bathrooms, Year Built, Lot Size, Garage Size and Neighborhood Quality.
